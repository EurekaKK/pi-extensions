# 需求记录

本目录保存仓库级需求。每个需求使用独立的 `REQ-NNNN.md` 文件，ID 一经分配不再复用；实现分支使用对应 ID 的小写形式和一至两个英文关键词：`req-NNNN-<slug>`。

## 创建新需求

从已同步且已跟踪文件干净的 `main` 分支运行：

```bash
npm run requirement:new -- --slug memory-export "增加 Memory 导出功能"
```

`--slug` 必须是一至两个小写英文或数字单词，两个词用一个连字符连接。命令会按顺序完成：

1. 从现有记录、Git 历史以及本地和远端分支名中分配下一个 `REQ-NNNN`。
2. 写入 `requirements/REQ-NNNN.md`，记录创建日期、目标分支和需求描述。
3. 创建并切换到 `req-NNNN-<slug>` 分支。

命令只检查已跟踪文件是否干净，未跟踪文件不会阻止创建。创建完成后，需求记录应与实现一起提交并合入 `main`。同一需求的补充工作沿用原 ID 和分支，不再运行创建命令。

同一 clone 同时只能执行一次分配；进程被强制终止而遗留锁时，确认没有分配命令运行后，按报错路径删除 `.git/new-requirement.lock`。多人协作时应先获取最新远端分支；脚本只能根据当前 clone 已知的记录和 refs 避免重复 ID。
