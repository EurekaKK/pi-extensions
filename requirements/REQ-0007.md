# REQ-0007

- 创建日期：2026-09-14
- 分支：`req-0007-eureka-ui`

## 描述

新增 eureka-ui extension：压缩并可选择性隐藏内置工具（read/bash/powershell/edit/write/grep/find/ls）在 transcript 中的调用与输出显示，把运行中的工具状态收敛到编辑器上方的状态行，让主要可见内容回到用户与模型的问答。仅接管内置工具渲染，不触碰其他 extension 注册工具的现有 renderer；工具执行行为保持不变。

## 已确认设计

- 每个内置工具三档显示：`hidden`（不渲染工具行）、`line`（一行摘要，原地更新）、`native`（保留 Pi 内置渲染，不注册覆盖）。
- 默认档位：read/grep/find/ls 为 `hidden`；bash 为 `line`；edit/write 为 `line`（展开显示 diff 统计与完整差异）；powershell 默认 `native`。
- `hidden` 档在工具运行中不渲染任何行，运行状态只在活动行显示；工具失败时破例渲染一行红色摘要，可展开完整输出。
- 展开语义：`Ctrl+O`（`app.tools.expand`）展开时，被接管工具显示 Pi 内置渲染的完整输出；渲染与执行都委托给 `createXToolDefinition` 工厂自带的实现，不重写 diff、高亮或截断逻辑。`line` 档行可点击单独展开。
- 活动行（activity line，编辑器上方独立 widget，key `eureka-ui:activity`）：普通文本一行、无符号/无边框/无背景、1 列内边距，句子式文案（`Running …` / `Ran … · 0.3s` / `Failed … · exit 1`），不采用 progress-widget 的"标记+标题+元数据"面板风格；并行时最多 2 条 + `+N`；全部结束后保留最后一条摘要到 `agent_settled`，错误保留到下一条用户消息；不接管 Pi 自带的 working indicator 与 thinking 提示。
- 活动行与 progress-widget 之间空一行（由活动行组件自己输出尾随空行），避免两者连成一块；空闲时整块渲染 0 行。
- 活动行在 `session_start` 注册一次并保持常驻（不重复 setWidget），`session_shutdown` 幂等清理；扩展加载顺序必须排在 progress-widget 之前，以保证活动行始终在 progress-widget 上方——`setWidget` 每次都会重插键、按插入顺序渲染，progress-widget 在内容由空转非空时会把自己排到末尾。
- 只接管内置工具，不注册通配渲染器；其他 extension（goal/plan/todo/sub-agent/memory/tavily 等）工具的渲染保持原样。
- 配置只有 `config.json` 一个入口，不提供 slash 命令；按 `config-store` 约定创建与严格校验，改后由 `/reload` 或重启生效（不做文件监听）。
- 配置损坏或不可读时 fail-closed：不注册任何覆盖（效果等于全部 `native`），只在 `session_start` 提示一次，不静默回退默认档位。
- 工具执行与展开渲染均委托内置 factory，参数 schema、描述与 prompt 文本与内置工具保持同步。
- 已知偏差：Pi 只在命令失败时提供退出码（`Command exited with code N`），因此 `line` 档与活动行的成功文案只含行数与耗时，失败文案含 `exit N`；powershell 仅在运行环境公开导出其 definition 工厂时可接管，否则自动保持 `native`。

## 验收范围

- 折叠态下 `line` 档每个工具至多一行摘要，`hidden` 档不占任何行；`native` 档与未安装本 extension 时显示一致。
- `hidden` 档运行中零行；失败时出现一行可展开的红色摘要。
- 展开内容与内置渲染等价（含 diff、截断提示、图片行）。
- 活动行的内容与生命周期符合「已确认设计」，样式为普通文本行并与 progress-widget 空一行隔开；与 progress-widget 等既有 widget 并存且互不干扰。
- 新配置文件的默认内容完整列出 8 个内置工具（含 `powershell: native`）；改后 `/reload` 生效。
- goal/plan/todo/sub-agent/memory/tavily 等 extension 工具的渲染保持原样，并有回归测试覆盖。
- 子代理子会话的工具行为不变：覆盖注册会改变内置工具的 `sourceInfo`，需实测子会话仍能获得 read/bash 等工具。
- `config.json` 缺失时按默认值创建；损坏时 fail-closed 且不阻止 Pi 加载；各运行模式（interactive / print / json / rpc）均能安全加载。
- 通过 `npm run check` 与 `npm test`，并在本机最新版 Pi 完成一次真实加载 smoke test（启动页 `[Extensions]` 显示 `eureka-ui`）。
