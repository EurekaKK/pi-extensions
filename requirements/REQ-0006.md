# REQ-0006

- 创建日期：2026-09-07
- 分支：`req-0006-subagent-lifecycle`

## 描述

修复 sub-agent 后台子会话冷恢复未重用原 session 导致上下文丢失，以及父 session 关闭未递归回收后代 Agent 的生命周期漏洞；补充冷恢复、递归关闭与并发清理回归测试。

## 验收范围

- 后台 spawn / fork child 结算并释放实例后，`send_message` 重新打开同一 session 文件，模型请求保留该 child 的历史；fork 不重新复制父会话。
- 恢复文件缺失、为空、无法识别或归属不匹配时报告失败，不静默新建会话。
- 父 session 关闭递归回收后代 Manager，包括其父运行实例已经释放或 one-shot 记录已经移除的后代。
- 关闭幂等，等待正在创建、运行、释放的实例；关闭后不继续执行排队消息或唤醒父会话。
- `interrupt_agent` 保持仅中断当前轮次的语义；磁盘 session 文件保留，正常重启不自动恢复子任务。
