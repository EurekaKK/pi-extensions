# REQ-0002

- 创建日期：2026-08-27
- 分支：`req-0002-widget-display`

## 描述

优化 progress-widget 的 TUI 显示，使浅色和深色主题下都保持清晰可读。

## 验收设定

- 区段标题保持 `accent` 配色和粗体，标题后的统计、轮次信息与 `Objective:` 标签同样使用 `accent` 强调色，但保持正常字重。
- 状态图标、Sub-agent 状态、ID 和正文分段配色；正文不使用粗体。
- 活动项正文使用 `text`，不再把进行中的 Todo 整行显示为 `warning` 黄色。
- 完成、失败、阻塞、待处理、暂停和中断状态使用 Pi Theme 的对应语义色及删除线等非颜色提示。
- 不硬编码 RGB 或背景色；RPC 的纯文本内容保持不变。
